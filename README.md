# vegvesen-cli

A Node.js CLI for Norwegian Public Roads Administration services.

> The CLI is currently a scaffold. Service commands will be added as the project develops.

## Requirements

- Node.js 20 or newer

## Run with npx

```sh
npx vegvesen-cli --help
```

## Install globally

```sh
npm install --global vegvesen-cli
vegvesen --help
```

## Development

```sh
npm install
npm test
node ./bin/vegvesen.js --help
```
