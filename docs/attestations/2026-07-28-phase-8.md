# Anonymous live smoke attestation — Phase 8 promotions

Date: 2026-07-28
Environment: production anonymous endpoints; no credentials or authorization headers.

## Purpose

The PLAN 4.3 promotions were classified from pinned specification metadata and existing
host attestations, without a live probe. This attestation exercises each promoted command
against production for the first time.

## Defects found and fixed

Three of the promoted commands were wrong, and none of the failures were visible offline:

1. `GET /api/v1/statistikk` and `/statistikk/nokkeldata` declare `dager` as a **required**
   query parameter. The command omitted it and returned HTTP 400. Now exposed as a required
   `--days` option.
2. NVDB Status system identifiers are UUIDs, not integers. The commands parsed them with the
   integer validator, so every exact system read failed. Now validated as opaque upstream
   identifiers.
3. `GET /api/v1/feilmeldinger/{systemId}` shares its path template with
   `GET /api/v1/feilmeldinger/{id}` (message by id). Upstream resolves the collision through
   content negotiation: the path answers 200 without an `Accept` header and 404 with
   `Accept: application/json`. Reaching it would require omitting a correct header, so it is
   excluded as a shadowed route. Its per-state sub-paths `/aktive` and `/planlagt` are
   unaffected and remain supported; `--system` now requires `--state active|planned`.

## Verified anonymously

Promoted commands: `nvdb status system get`, `system health`, `statistics get` (both
projections), `message list --system --state active`, `message list --state latest|closed`,
`nvdb report reference list` (load-class, contract-area, kostra-type), `report custom list`,
`nvdb catalog type property`, `fiks issue list --detailed`.

Regression across the existing surface: `nvdb object list`, `nvdb network link list`,
`catalog package search`, `traffic station list`, `route calculate --profile best`,
`parking provider active`, `tnits type list`.

All returned HTTP 200 with valid envelopes. No credentials, authorization headers, or cookies
were sent. No mutation was executed.
